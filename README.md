# SS14 Nuclear Bruteforce
Python скрипт для подбора кода ядерной бомбы в игре Space Station 14

### 🎮 Использование
* Вставьте диск в бомбу, закрепите
* Запустите скрипт, выберите режим работы
* Наведите мышь на цифру 1 в интерфейсе ввода кода
* Нажмите insert
* Скрипт переберёт все возможные комбинации

### 📥 Сборка из исходников
1. Клонируйте репозиторий:
```bash
git clone https://github.com/R-R0S/SS14-NuclearBruteforce.git
cd SS14-NuclearBruteforce
```
2. Установите зависимости:
```bash
pip install -r requirements.txt
```
3. Запустите приложение:
```bash
python main.py
```

### 📦 Требования
* Python 3.9+
